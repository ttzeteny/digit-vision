# DigitForge

A full-stack handwritten digit recognition application powered by a neural network.

The project is being built from the ground up as a learning project, with an emphasis on understanding the machine learning, software engineering, and deployment decisions behind the system.

## Tech Stack

### Machine Learning
- Python
- PyTorch
- torchvision
- NumPy
- pandas
- Matplotlib
- Seaborn

### Backend
- FastAPI

### Frontend
- React
- TypeScript
- Vite
